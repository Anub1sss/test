# Котоферма

Полный Docker-сервис по ТЗ: Django + DRF API, Angular frontend, WebSocket-сообщения, Postgres, Redis и Nginx.

## Запуск

```bash
docker compose up --build
```

Приложение: `http://localhost:8080`

## Что есть

- Регистрация и вход заводчика через JWT.
- REST API для котов: создание, список, редактирование, удаление.
- Заводчик видит и меняет только своих котов.
- Расширенный паспорт кота: имя, возраст, порода, волосатость, окрас, характер, подробное описание, питание, лоток, игрушка, прививки, фото.
- Статусы котов: ищет дом, забронирован, остаётся в питомнике.
- Лента котов: фото, описание, лайки, цена, фильтры по заводчику, породе и статусу.
- Быстрый переход из карточки кота в чат с его заводчиком.
- Форум/библиотека с темами по уходу, здоровью, питанию, поведению, разведению и историям.
- Раздел сообщений с WebSocket-отправкой другим заводчикам.
- Angular Material интерфейс с адаптивной версткой, фильтрами, статистикой и карточками питомника.
- Docker-сборка frontend/backend и reverse proxy через Nginx.
- Админка Django для управления аккаунтами, котами, лайками и сообщениями.

## Админка

Адрес: `http://localhost:8080/admin/`

По умолчанию для локального запуска создаётся админ:

- логин: `admin`
- пароль: `admin12345`

Значения можно переопределить через `DJANGO_SUPERUSER_USERNAME`, `DJANGO_SUPERUSER_EMAIL`, `DJANGO_SUPERUSER_PASSWORD`.
